Exploring imaging data

Purpose

Inspect spatial patterns and follow how a selected pixel changes through time.

Prerequisites

Open an image time series in DataViewer.

  1. Click a brain location in Image View. The crosshair moves and the temporal profile updates.
  2. Drag the frame slider, use the previous/next buttons, or click Play.
  3. Choose a playback multiplier from the speed list.
  4. Select a Colormap, optionally enable Invert, and adjust the Clip range.
  5. Choose Auto to recalculate display limits or Set Limits to enter exact values.
  6. If events are available, move the switch to Event mode, then select a condition and repetition or AVERAGE.


Event mode shows an event-aligned image and trace for the selected condition.

Expected result

The image title reports the frame and mode. Display limits and colormap change the appearance only; the values in the data source stay unchanged.

What is saved

Frame selection, playback, crosshair position, colormap, and clipping are display state. Deleting an event condition or repetition changes only the current selection state in memory until a tool explicitly saves event metadata.

Troubleshooting

ProblemAction
Event mode is unavailableCreate or repair events.mat with Events Manager.
Playback is slowUse a lower speed. Disk-backed data may be limited by storage performance.
