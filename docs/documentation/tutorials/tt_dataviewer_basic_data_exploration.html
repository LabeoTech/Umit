Exploring imaging data

Use DataViewer to inspect spatial patterns and follow how a selected pixel changes through time.

Basic operations

First, open an image time series in DataViewer.

  1. Click a brain location in Image View. The crosshair moves and the temporal profile updates.
  2. Drag the frame slider, use the previous/next buttons, or click Play.
  3. Choose a playback multiplier from the speed list.
  4. Select a Colormap, optionally enable Invert, and adjust the Clip range.
  5. Choose Auto to recalculate display limits or Set Limits to enter exact values.
  6. If events are available, move the switch to Event mode, then select a condition and repetition or AVERAGE.


Event mode shows an event-aligned image and trace for the selected condition.

What is saved?
Frame selection, playback, crosshair position, colormap, and clipping affect only the current display. Ignoring an event condition or repetition is different: that selection is recorded in events.mat and is also ignored by later event-based analysis.
