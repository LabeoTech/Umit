Exploring temporal traces

Purpose

Compare the time course of a selected pixel and visible ROIs without first exporting data.

Prerequisites

Open Y-X-T data. Create or load at least one ROI for ROI traces.

  1. Click a pixel to update the black temporal profile.
  2. Make one or more ROIs visible in the ROI table. A colored mean trace appears for each visible ROI.
  3. Move the frame slider and confirm that the vertical time marker and current-frame ROI statistics update.
  4. Switch to Event mode to compare a condition, repetition, or average when event information exists.
  5. Choose ROIs > Export ROI data to export spatial measurements, continuous time vectors, or event-aligned time vectors.

Expected result

The plot legend identifies the pixel and ROI traces. The ROI table reports current-frame measurements such as mean intensity and geometry.

What is saved

Trace calculation is read-only and may use a disk cache. Export writes CSV files selected in the export dialog. It does not change the ROI file or imaging data.

Troubleshooting

ProblemAction
No ROI trace appearsConfirm the ROI is visible, overlaps the image and logical mask, and the data has a time dimension.
Event trace has no baselineReview baselinePeriod in Events Manager or the UMT event information.

For calculations intended for later statistics, run getDataFromROI in a pipeline.
