Exploring temporal traces

Compare the time course of a selected pixel and visible ROIs without first exporting data. Open Y-X-T data, then create or load at least one ROI.

  1. Click a pixel to update the black temporal profile.
  2. Make one or more ROIs visible in the ROI table. A colored mean trace appears for each visible ROI.
  3. Move the frame slider and confirm that the vertical time marker and current-frame ROI statistics update.
  4. Switch to Event mode to compare a condition, repetition, or average when event information exists.
  5. Choose ROIs > Export ROI data to export spatial measurements, continuous time vectors, or event-aligned time vectors.


The visible red ROI appears in the table and contributes the matching red trace to the temporal plot.

What is saved?
Trace calculation is read-only and may use a disk cache. CSV export is an option in the ROIs tab under Export ROI data; see Save, load, import, and export. The export does not change the ROI file or imaging data.

For calculations intended for later statistics, run getDataFromROI in a pipeline. Event response features require the ordered workflow split_data_by_event → getDataFromROI with spatial aggregation enabled → calculateResponseFeatures.
