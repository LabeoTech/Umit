Introduction to DataViewer

Purpose

DataViewer is the main workspace for opening mesoscale imaging data, moving through frames and events, inspecting pixel and ROI signals, and sending the current recording to processing and project tools.

Prerequisites

Start MATLAB with umIT on the path. To open data immediately, have a supported .dat or image-kind .umt file available.

Open the app

  1. Run DataViewer in MATLAB, or run DataViewer("path/to/file.dat").
  2. If no file was supplied, choose File > Open.
  3. Check the status line and the recording context shown above the image.


Current DataViewer: application tabs, image, temporal profile, ROI table, and event controls.

What you are looking at

AreaPurpose
Utilities, Pipeline, ROIsOpen related tools, configure processing, and create or manage ROIs.
Image ViewShows the selected frame. Clicking a pixel moves the crosshair and updates the temporal profile.
Temporal ProfileShows the selected pixel or visible ROI signals over time.
ROI tableControls ROI selection, visibility, names, colors, and measurements.
EventsSwitches between continuous and event-aligned views when valid event metadata exists.

Expected result

The image, frame controls, temporal profile, and file context are populated. Missing optional metadata disables only its dependent features.

What is saved

Opening and viewing data does not change the imaging file. Display choices stay in memory unless a specific save or export command says otherwise.

Troubleshooting

ProblemAction
A .dat file will not openConfirm that valid AcqInfos.mat metadata is in the same Save Folder.
Project tools are disabledBind the Save Folder to a project, subject, and session.
