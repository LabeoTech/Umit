Basic processing workflows

The Pipeline Manager builds and runs a reproducible sequence of analysis functions on the active recording. Open a .dat or .umt file with an accessible Save Folder first.


The Pipeline tab opens the manager and summarizes the current input, pipeline state, and most recent result.

The app lists available functions on the left, shows the processing graph in the center, and displays the selected step and its parameters on the right. The main file, data, and run controls are along the top.

  1. Open the Pipeline tab and choose Pipeline Manager.
  2. Search the function list, select a compatible function, and choose Add.
  3. If prompted, choose the source for each required input.
  4. Right-click a graph step and choose Edit Parameters to review its options.
  5. Add later steps in the desired order. Use Add as New Branch when two paths should process files independently.
  6. Choose Run, review the execution plan, and confirm.
  7. After completion, select an image result to open it in DataViewer. Save any temporary result needed later.


The current image file is the starting point shown in the graph; analysis functions are added from the searchable list.

What is saved?
Image results returned to DataViewer are temporary by default. Save any result that must remain in the Save Folder. Permanent outputs and the processing records in dataHistory.mat and pipeLog.mat are written by Pipeline Manager.

Review destructive functions.
applyRegistrationTformOnFolder rewrites every .dat file in place and is effectively irreversible.
