Basic processing workflows

Purpose

Build and run a small, reproducible sequence of analysis functions on the active recording.

Prerequisites

Open a .dat or .umt file with an accessible Save Folder.

  1. Open the Pipeline tab and choose Pipeline Manager.
  2. Search the function list and select a compatible function.
  3. Choose the source for each required input and select Add. Add later steps in the desired dependency order.
  4. Select a graph node to review its parameters and saved-output state.
  5. Choose output persistence and RAM options. Keep the DataViewer default temporary-output policy for exploratory work.
  6. Choose Run and review the execution plan or confirmation.
  7. After completion, select a viewer-compatible output to open it in DataViewer. Save any temporary result you need before switching files or closing.


The current file is a virtual source node; analysis functions are added from the searchable list.

Expected result

The activity log and execution view show completed steps. Compatible image results can return to DataViewer; reports or other terminal outputs remain files.

What is saved

The policy controls persistence. Temporary files use the PMTMP_ prefix and are cleaned at lifecycle boundaries unless saved. Permanent outputs, dataHistory.mat, and pipeLog.mat are written by PipelineManager.

Review destructive functions.
applyRegistrationTformOnFolder rewrites every .dat file in place and is effectively irreversible.
