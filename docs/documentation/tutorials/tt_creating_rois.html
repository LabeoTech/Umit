Working with ROIs

Purpose

Create regions of interest (ROIs) for cortical areas or other structures and compare their signals.

Prerequisites

Open image data. A project binding is not required for ordinary ROI drawing or ROI files.

  1. Open the ROIs tab.
  2. Choose Rectangle, Ellipse, or Polygon, then draw on the image.
  3. Use the ROI table to select, show or hide, rename, recolor, and inspect the ROI.
  4. Select an ROI to edit it. Confirm the edit, or cancel it to restore the stored shape.
  5. Use Save to write a schema-validated .roi file. Use Load to replace or append ROIs.


The current ROI tab includes drawing, threshold, Allen Atlas, file, import, and export tools.

Allen Atlas ROI Creator

Allen Atlas opens the creator inside the ROI workflow; it is not a separate project resource page.

  1. Choose Allen Atlas.
  2. Search by area name or browse the Neocortex tree.
  3. Check individual areas or modules. Use a module's context menu to merge or unmerge its regions.
  4. Choose Remember selection if you want the same checked regions proposed next time, then choose OK.
  5. Move and resize the placement box over the brain image. Confirm placement to create the ROI set, or cancel to leave the current ROI list unchanged.
  6. Review the generated ROIs in the table and edit them like manually drawn ROIs.


Search, tree selection, and the interactive atlas map use the current Allen Atlas ROI Creator.

Atlas limitations
The atlas is a two-dimensional placement aid, not an anatomical registration guarantee. Check coverage against the displayed cortex. Atlas geometry outside the active logical mask can be clipped, and an unsuitable orientation or damaged field of view requires manual correction.

Expected result

Each ROI appears as an overlay and a row. Visible ROI traces are calculated from the current data.

What is saved

Drawing, editing, thresholding, Boolean operations, and atlas placement are in memory until Save. A .roi file stores geometry and metadata; it does not alter imaging samples. Remember selection stores only the atlas selection preference.

Troubleshooting

ProblemAction
