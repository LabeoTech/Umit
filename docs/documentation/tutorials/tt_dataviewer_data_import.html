Opening data

DataViewer opens existing UMIT image data and can start an import of raw binary or TIFF recordings into a Save Folder. For .dat, keep AcqInfos.mat beside the file. For .umt, select an image entry with supported dimensions.

Open an existing file

  1. Select File > Open.
  2. Choose a .dat or .umt file.
  3. If the UMT contains several compatible image entries, select one in the entry dialog.
  4. Wait for the loaded filename and frame count to appear.

Import a recording

from bin imports recordings produced by the OiS200 LightTrack widefield imaging system. from tif accepts generic TIFF image sequences produced by other rigs.

  1. Choose File > Import > from bin or from tif.
  2. Select the raw source and a Save Folder when prompted.
  3. Review the import options and start the import.
  4. Open one of the generated .dat files.

Keep acquisition metadata together.
DataViewer will not guess image dimensions for a .dat file when AcqInfos.mat is missing or invalid.

What is saved?
Open is read-only. Import creates processed data and acquisition metadata in the selected Save Folder. File > Set Raw Folder updates DataParams.mat; it does not move raw data.
