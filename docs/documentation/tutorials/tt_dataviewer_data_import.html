Opening data

Purpose

Open existing UMIT image data or import raw binary or TIFF recordings into a Save Folder.

Prerequisites

For .dat, keep AcqInfos.mat beside the file. For .umt, the selected entry must be image-kind data with supported dimensions.

Open an existing file

  1. Select File > Open.
  2. Choose a .dat or .umt file.
  3. If the UMT contains several compatible image entries, select one in the entry dialog.
  4. Wait for the loaded filename and frame count to appear.

Import a recording

  1. Choose File > Import > from bin or from tif.
  2. Select the raw source and a Save Folder when prompted.
  3. Review the import options and start the import.
  4. Open the generated .dat file.

Keep acquisition metadata together.
DataViewer will not guess image dimensions for a .dat file when authoritative AcqInfos.mat metadata is missing or invalid.

Expected result

The first frame appears, the slider spans the available frames, and the temporal profile is calculated for the center pixel.

What is saved

Open is read-only. Import creates processed data and acquisition metadata in the selected Save Folder. File > Set Raw Folder updates DataParams.mat; it does not move raw data.

Troubleshooting
