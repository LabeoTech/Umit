Minimal requirements

The umIToolbox is compatible with MATLAB R2024b and newer.
The following MATLAB toolboxes are necessary to run all modules of umIT:

  • Image Processing Toolbox
  • Signal Processing Toolbox
  • Statistics and Machine Learning Toolbox (*necessary only for the umIToolbox app)

Regarding the hardware requirements, we recommend any computer with at least 32GB of RAM and an SSD hard drive.
