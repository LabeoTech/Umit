User interface

Menus

ControlAvailable whenEffect and persistence
File > OpenAlwaysOpens .dat or image-kind .umt; read-only.
File > SaveData is loadedSaves the current data under a chosen supported name.
File > Import > from bin/from tifAlwaysCreates processed data and metadata in a Save Folder.
File > Export > to tifCompatible image data is loadedWrites TIFF output; the source remains unchanged.
File > Set Raw FolderData and an accessible Save FolderStores a selected path, the Save Folder itself, or Missing in DataParams.mat.
Help > Online documentationAlwaysOpens the documentation site.

Utility dialogs

View Calibration reports pixel scale, coordinate origin, and available calibration state. Logical Mask can create, preview, confirm, reset, or automatically derive a mask. Data History shows the current file's processing provenance. Status messages appear at the top-left context area with warning or error severity when action is needed.
