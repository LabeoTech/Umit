Processing and export

Pipeline context

DataViewer keeps one PipelineManager context per active Save Folder. The current file is represented as a virtual file-source node. Closing Pipeline Manager preserves the graph and last result so it can be reopened. Switching Save Folders resets that context after temporary-output cleanup.

Returning results

After a run, DataViewer separates permanent, temporary, and viewer-compatible outputs. If several compatible images exist, an output-selector dialog shows file, source step, output name, type, and persistence. Non-image reports and terminal results stay on disk and are summarized rather than opened as images.

Temporary output lifecycle

DataViewer-managed temporary files start with PMTMP_. Saving the current temporary file writes a permanent copy. Opening another file, closing the app, or resetting context can remove temporary files after any required confirmation.
