ROI management

ROI management is integrated into DataViewer. An ROI is a named shape used to summarize pixels over space and time.

Create ROIs

Allen Atlas selection and placement

  1. Search for an anatomical label or expand the Neocortex tree.
  2. Check an area or module. Selecting a result synchronizes the map and tree.
  3. Use a module context menu to Merge module or Unmerge module.
  4. Choose OK. DataViewer opens a placement box and live preview over the current image.
  5. Move, resize, or adjust placement. Confirm to add the selected areas; cancel restores the previous ROI list.


The creator searches and selects regions; final placement occurs in DataViewer.

Scientific limitation
The atlas overlay is a user-positioned two-dimensional approximation. It does not estimate a transform, verify anatomical correspondence, or replace visual quality control.

ROI table and editing

The table controls Visible, Select, Name, type, color, centroid, size, and current-frame statistics. A selected ROI can enter editable mode. Multi-selection supports grouped edits and Boolean operations such as merge, intersect, XOR, and subtract; operations that would create unsupported holes are blocked. Deleting selected or all ROIs asks for confirmation.

Logical mask interaction

Creating or changing a logical mask can clip existing ROIs. DataViewer reports how many ROIs were changed and asks before deleting any that would become empty.
