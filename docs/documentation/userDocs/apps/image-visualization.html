Spatial units

When valid pixel calibration and origin exist in DataParams.mat, axes and ROI measurements can use physical coordinates. Otherwise the app shows pixels and a neutral origin. View Calibration reports the active state without modifying it.

Cache behavior

For large .dat recordings, DataViewer can cache a spatial region through time. Cache controls affect read performance and memory use, not file contents. Direct disk access remains available when a selected pixel or ROI is outside the cached region.
