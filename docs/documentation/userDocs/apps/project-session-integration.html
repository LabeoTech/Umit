Project and session integration

A Save Folder can point to one centralized project, subject, and session through UMITProjectBinding.umitlink. The link contains immutable identifiers and location hints; project metadata and managed resources stay in the centralized store.

Binding states

StateMeaningAvailable actions
UnboundNo link file exists.Ordinary viewing works; project-dependent tools offer Project Binding Manager.
ValidThe project, subject, session, role, and folder agree.Image references, alignment, and project metadata are available.
Read-onlyThe link resolves but project validation did not pass.Viewing and reference inspection may work; writes are blocked.
Missing projectThe link points to a project UUID not found under the project root.Retry, reassign, or explicitly remove an orphan link.
Invalid/conflictingThe link is malformed or identity/path facts disagree.Automatic replacement is blocked; inspect and repair deliberately.

Refresh behavior

DataViewer resolves the binding after every load. When Project Manager closes, it resolves the current dataset again. Image Alignment Tool refreshes DataViewer after a successful apply: the current file is reopened when possible, project context is refreshed, and loaded ROIs are cleared because their coordinates may now be stale.

Ownership boundary

Save Folder                          Central store
-----------                         -------------
recording data and view state  -->  link by UUID only
applied transform UUID + QC         project/subject/session identity
                                   managed references and transforms
