Temporal visualization

Normal mode

The temporal plot shows the selected pixel over the source time axis. Valid frame rate metadata converts samples to seconds. Event intervals from events.mat appear as shaded patches. Moving the frame control updates the time marker.

ROI traces

Every visible, non-empty ROI contributes its spatial mean trace. DataViewer reads from the temporal cache when possible and otherwise reads the necessary pixels directly from disk. Changing ROI geometry, visibility, mask, data file, or event selection recalculates the relevant traces.

Event mode

For continuous .dat, DataViewer builds event-relative frame selections from normalized events.mat. For UMT, it uses top-level eventInfo and the entry's declared event axis. AVERAGE displays the repetition mean and, where available, its standard error.
