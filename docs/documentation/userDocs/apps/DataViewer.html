DataViewer overview

DataViewer opens continuous .dat recordings and image-kind .umt data without loading an entire large recording into memory. It combines image navigation, temporal signals, ROIs, event-aligned viewing, processing, and project-aware tools in one window.


Current DataViewer using a demonstration fluorescence recording.

Launch

DataViewer
DataViewer("C:\data\session\green.dat")
DataViewer("FilePath","C:\data\session\result.umt")

Supported sources

SourceRequired informationBehavior
.datValid AcqInfos.mat in the Save FolderReads single-precision frames and traces directly from disk, with an optional spatial-temporal cache.
Image-kind .umtValid UMT schema and a compatible image entryUses the entry's declared dimensions, labels, and event information.

Application data flow

Save Folder (.dat/.umt + metadata)
        |
        v
   DataViewer ----> ROI tools and temporal display
        |
        +----> Pipeline Manager / Events Manager
        |
        +----> project binding ----> references, alignment, project manager
        |
        +----> rig context --------> dual-camera coregistration

Optional metadata degrades safely.
Missing DataParams.mat uses pixel coordinates and a full mask. Missing events.mat disables event features. A .dat file without valid AcqInfos.mat cannot be reconstructed safely.

Persistence at a glance

Navigation and display controls are temporary. A command writes to disk only when its page says so. See Processing and export and Save Folder metadata files.
