Data loading and navigation

Loading sequence

  1. DataViewer validates the selected file and constructs a disk-backed .dat source or a UMT entry source.
  2. For a UMT with several compatible image entries, the entry selector lists names, dimensions, and sizes; cancel leaves the current file unchanged.
  3. DataViewer loads optional DataParams.mat, resolves any UMITProjectBinding.umitlink, and initializes event information.
  4. The first frame, crosshair, time trace, ROI calculations, cache display, and enabled controls refresh together.

Changing files safely

Opening another file resets the source and project context. ROIs intentionally remain loaded when their image size is compatible, and their traces are recalculated. Before switching, DataViewer asks how to handle a currently displayed PipelineManager temporary result. Save any result that must persist.

Do not infer dimensions from file size.
AcqInfos.mat is authoritative for .dat reconstruction. A file-size match is not a substitute for valid metadata.
