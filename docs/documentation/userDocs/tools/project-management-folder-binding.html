Project management and folder binding

Project Manager organizes project metadata and managed resources. Project Binding Manager assigns one external Save Folder to one project subject/session. They are documented together because both establish the context required by Image Reference Manager and Image Alignment Tool.

Open from DataViewer

Choose Utilities > Project Manager. If the current Save Folder already resolves, the matching store opens; otherwise you can open or create a project. Project Binding Manager opens automatically when an unbound folder requests a project-dependent tool, and can also be used for explicit reassignment and repair workflows.

Project Binding Manager chooses an existing or new project, subject, and session for the current Save Folder.

Project Binding Manager

  1. Choose Use existing project or Create new project.
  2. Select or create a subject, then select or create a session.
  3. Review the current Save Folder and action label: Bind Folder, Rebind Folder, or Use Binding.
  4. Confirm. The manager writes UMITProjectBinding.umitlink and updates the centralized session processed-folder locator transactionally.

Unbinding, recovery, and repair

Unbinding is explicit; no tool silently overwrites a link. A missing-project link offers retry, reassignment, or orphan-link removal. Malformed or conflicting UUID/path ownership is protected from automatic reassignment. Use Project Manager validation and Repair Binding only after confirming the intended project, subject, session, and folder.

DataViewer refresh

When either manager closes, DataViewer resolves the link again and updates the project/Save Folder context and enabled tools. Project metadata never absorbs the bulk imaging files.

UUIDs are identity; paths are locators.
Do not repair a moved drive by creating duplicate project records or hand-editing .umitlink. Use the binding and relocation actions.
