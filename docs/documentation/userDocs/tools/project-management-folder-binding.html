Project management and folder binding

Project Manager organizes project information and subject reference libraries. Project Binding Manager associates one Save Folder with a new session of a project subject. They are documented together because both create and maintain the link between a Save Folder and its project. Projects are optional: see Project and session integration.

Open from DataViewer

Use Management > Project > Bind Current Session... to open Project Binding Manager for the loaded Save Folder. Use Management > Project > Project Manager... for full project administration. Binding problems of the loaded folder are repaired from Management > Project > Repair Folder Binding... (see below).

Project Binding Manager

Project Binding Manager binds the current Save Folder to a new session. Existing sessions are not offered, because binding one would take it away from its own Save Folder; to point an existing session to another folder, use Rebind / Relocate in the Project Manager.

  1. Choose Use existing project or Create new project in Project mode.
  2. Select a subject or create one with New subject.
  3. Click New session and fill in the Add Session dialog (session ID, display name, description, acquisition date). The Rig field shows the rig recorded in the folder's rig ledger, for information only.
  4. Review the status line and click Bind Folder. The manager creates what you asked for (project, subject, session) and writes the folder's project ledger as one operation: if a step fails, nothing that was created stays behind.


The Add Session dialog previews the folder's rig; it is not stored in the session.


Ready to bind the Save Folder to the new session.

When the folder is already bound, the manager opens in rebind mode (Rebind Folder), again to a new session; Use Binding keeps the current binding. After a binding change, DataViewer checks whether the folder's alignment reference is already in the subject's library and, if not, offers to add it (see Adding a folder's reference to the library).

Binding states and repair

The binding of a Save Folder is read from its project ledger and compared with the projects on this computer. Reading never changes the folder. DataViewer reports a problem in the status line when the data are loaded; Management > Project > Repair Folder Binding... then offers the fitting repair:

StateMeaningRepair
UnboundThe folder has no project ledger, or its binding was removed (the history stays).Nothing to repair; bind it if you want a project.
Project unavailable (orphan)The project the folder is bound to is not on this computer, for example a disconnected drive or another computer.The Project Unavailable dialog offers Retry (after reconnecting the drive), Reassign Folder (bind the folder to a new session of an available project) and Remove Binding.
Stale linkThe project is here, but no session binds this folder any more (the session was removed, moved or rebound while the folder was offline).The Stale Project Link dialog offers Remove Link and Bind... and Remove Link. Removing the link is recorded in the folder's project ledger.
Conflict, invalidThe project is registered twice on this computer, or the project ledger is damaged or was edited by hand.An alert explains the problem. Resolve duplicated projects in the projects root; restore a damaged ledger from a backup.
Path mismatchThe session binds this folder, but its registered location differs (a moved or copied folder).Use Rebind / Relocate or Repair Binding in the Project Manager.

Folders bound with an earlier development version kept a UMITProjectBinding.umitlink file. That file is no longer read: such a folder reads as unbound; bind it again.

"Locked" errors

Project and ledger changes take a short lock. If a change was interrupted (for example MATLAB closed), the lock can stay behind and the next change reports that the project or folder is locked. DataViewer, Project Binding Manager, the Project Manager and the Folder Rig dialogs then offer Clear Stale Lock. Only an old lock is cleared: at least 60 minutes for a project, 10 minutes for a folder ledger. A recent lock is kept, because another operation may still be running; wait and try again.

DataViewer refresh

When either manager closes, DataViewer reads the folder's project ledger again and updates the context line and the available commands.

Rig binding is a separate, independent concept from project binding — see Folder rig and Rigs and Optical Library.

Use the managers when a project or folder moves
Do not create duplicate project records or hand-edit UMITProjectLedger.json. Use Rebind / Relocate or Repair Binding so the existing subject and session identity is preserved.
