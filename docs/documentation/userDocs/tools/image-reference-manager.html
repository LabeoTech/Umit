Image Reference Manager

An image reference is a fixed 2-D image used to align recordings consistently with the Image Alignment Tool. With a project, references are kept in each subject's reference library, so all sessions of a subject can share one. Without a project, a reference is saved as a standalone reference file. A project is not required.

Open from DataViewer

Load image data and choose Utilities > Image Reference. The manager opens in one of two modes:

  • Library mode, when the Save Folder is bound to a project session: the window title names the subject, and the table lists the subject's references. Read-only projects may view references, but creating, editing, activating, archiving, or restoring requires writable project access.
  • Standalone mode, when the Save Folder is not bound to a project: the window title reads no project, and a reference is created and then exported as a file.

DataViewer passes the current 2-D frame, the source frame number, the source file and, in library mode, the project, subject and session.

Standalone mode (no project)


Standalone mode: create a reference, then export it.

  1. Choose Create from current frame or Create from file, and enter a name, description and processing notes.
  2. Inspect the preview.
  3. Choose Export... and save the reference file.

The reference file can then be selected in the Image Alignment Tool (source Reference File), for this folder and others, or imported into a subject library later.

Basic workflow (library mode)

  1. Select an existing row, or choose Create from current frame or Create from file.
  2. Enter a clear name, description, and processing notes.
  3. Inspect the preview and image size.
  4. Optionally choose Edit, apply an affine adjustment to the framing, and confirm the edited reference.
  5. Choose Set Active when this should be the subject's default alignment reference.

Adding a folder's reference to the library

A folder that was aligned without a project keeps a copy of its reference image in DataParams.mat. Once the folder is bound to a project session, Management > Project > Add Folder Reference to Library... in DataViewer compares that image with the subject's library:

  • if the library already holds the same image (active or archived), the match is only reported, and nothing is changed;
  • otherwise the dialog Add Folder Reference to Library offers Add to Library, Add and Make Active or Not Now.

The folder itself is never changed. DataViewer also makes this offer quietly after a folder's project binding changes.

DataViewer refresh

The manager changes the reference library or writes a reference file; it does not change the displayed pixels or the folder's alignment.

Preserve the managed history
Library references are identified by UUID. Do not edit or replace their files directly. Archive and restore them only through the manager.
