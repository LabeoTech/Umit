Image Alignment Tool

Image Alignment Tool estimates and reviews a 2-D transform from the current moving image to a subject image reference, then optionally applies that transform to the entire Save Folder.

Open from DataViewer

Load .dat or image-kind .umt data and choose Utilities > Alignment Tool. A writable project/session binding is required. DataViewer passes the current frame as a locked moving source, source description, target Save Folder, and project/subject/session identifiers.


The real two-camera demonstration frame is loaded as the moving source; no reference or transform was created for this capture.

Prerequisite: create an image reference

  1. Open Utilities > Image Reference.
  2. Choose Create from current frame or Create from file.
  3. Inspect it and choose Set Active.
  4. Return to Alignment Tool and choose Select Image Reference.

Controls and workflow

ControlMeaning

Transformation, Step size, Apply StepFine-tunes horizontal/vertical translation, rotation, or scale.
Reset Fine Tuning / Reset RegistrationRemoves manual adjustments or the full candidate.
Apply Registration to FolderRegisters the transform as a session-managed resource, records the local applied resource UUID and QC state, and rewrites target data after confirmation.

Destructive and effectively irreversible
Applying registration rewrites every .dat file in the target folder. Interpolation and out-of-frame loss cannot be reliably undone. Back up the Save Folder, review the impact summary and ROI warning, and confirm only once.

ROI and refresh behavior

The impact dialog reports loaded ROI risk. After a successful apply, DataViewer reloads the most suitable current file, refreshes project state, and clears loaded ROIs because their coordinates may be stale. Save or export important ROI definitions before alignment and transform/recreate them afterward.

Close behavior

Closing with an unsaved candidate asks for confirmation. Preview, view mode, and fine-tuning are temporary until apply.
