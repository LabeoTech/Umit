Pipeline Manager

Pipeline Manager builds a directed processing graph and executes compatible analysis functions on one or more Save Folders.

Open from DataViewer

Load .dat or .umt data, open the Pipeline tab, and choose Pipeline Manager. DataViewer passes the current Save Folder, Raw Folder state, file, persistent PipelineManager object, last result, and completion callbacks.


The current file enters the graph as a virtual source. Function categories come from live PipelineManager discovery.

Basic workflow

  1. Select a function. PipelineManager uses semantic input and output types to determine valid connections.
  2. Choose each input source. File inputs and data inputs are distinct; a function accepts filenames only when it declares and implements file support.
  3. Edit parameters and output-saving choices.
  4. Review the execution plan and run.
  5. Inspect the activity log, folder pipeLog.mat, result summary, and any issues.

Outputs and DataViewer refresh

Returned arrays or UMT structures can feed downstream steps. Functions may instead create a declared file manifest. Image-compatible results can be selected and opened in DataViewer; scalar tables, reports, and other terminal outputs are summarized but not displayed as images. On close, DataViewer retains the graph and last result, restores its window, and cleans temporary files only at defined lifecycle boundaries.

Batch data folders

Data Folders can add Save Folder/Raw Folder pairs, discover child folders, filter them, mark unavailable raw data as Missing, and enable or disable rows. A required Raw Folder input causes an incompatible row to be skipped rather than guessed.
