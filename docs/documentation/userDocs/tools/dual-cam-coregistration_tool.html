Dual-Camera Coregistration

This tool is dedicated to performing the coregistration of images from Dual-Camera Imaging systems from LabeoTech. Its goal is to ensure that the outputs of both cameras are aligned.

Open from DataViewer

Choose Utilities > OiS 2-Cam Alignment. The active Save Folder must have AcqInfos.MultiCam=true. DataViewer passes the folder and, when available, rig plus project/subject/session context.


The current tool with the approved multi-camera demonstration context. No coregistration was saved during capture.

Normally a one-time hardware calibration
Repeat the calibration when a camera is moved, the optical path changes, or image alignment no longer passes visual quality control. Once a calibration is active, a dual-camera data-import function such as run_ImagesClassification automatically applies it to camera-2 data during import.

Important source rule

Choose Load Coregistration Data and select an unregistered set of imported dual-camera .dat files. Do not estimate a new calibration from processed files that may already have the active camera transform applied.

Files and application of the transform

Save Coregistration does not rewrite the calibration-source images. It saves the transform and preview information as a managed resource for the selected rig and records the active resource in the source folder's DataParams.cameraCoregistration.

When that calibration is applied during dual-camera import or by the controlled application helper:

  • camera-2 channel .dat files are warped in place with nearest-neighbour interpolation;
  • camera-1 .dat files are not changed;
  • AcqInfos.mat supplies channel, camera, size, binning, flip, and rotation information but is not itself geometrically transformed;
  • a local tformDualCam.mat copy records the adjusted transform used for that processed folder.

Where the calibration is stored

The full calibration belongs to the rig's managed coregistration history. Its record includes tform, tformInfo, source and creation information, and stored preview images. The source folder's DataParams.cameraCoregistration keeps the active resource identifier and local application summary. Use Browse Coregistration History to identify the active and previous calibrations; do not delete managed files manually.

Quality control

Use Alternate View and False Color Overlay to compare vessels and field-of-view borders from both cameras before saving. The local QC summary records translation in pixels, rotation in degrees, X/Y scale, and the transform determinant. These values help identify unexpectedly large or reflected transforms but do not replace visual inspection.

DataViewer refresh

DataViewer waits for the utility to close and then reports closure. The currently displayed data is not automatically rewritten by this utility.

Rig-level resource
Camera coregistration belongs to the rig, not one subject. Verify the physical camera arrangement before making a transform active.
