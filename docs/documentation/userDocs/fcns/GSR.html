GSR - Global Signal Regression

Removes global variance from imaging data.

Description

The Global Signal Regression is commonly used in brain imaging to remove signal oscillations that is present all over the surface of the brain (i.e. global). Some global oscillations may arise from other sources than the brain itself such as breathing and cardiac activity [1-4]. Thus, the main assumption used to perform GSR is that the source(s) of global signal fluctuations are considered as noise and ought to be removed.

Input

This function accepts image time series with dimensions Y, X and T, or image time series split by events with dimensions Y, X, T and E, either as a single-precision array or as a .dat file. UMT structs and .umt files are not supported.

When the input is a .dat file, it is processed in spatial chunks directly from disk (Low-RAM mode), so the recording is never loaded whole.

The algorithm

In brief, this function uses the average signal of all pixels from the image (or selected region) as a regressor in a linear model which results in the global component of the signal. Then, the global signal is subtracted from the original data.

Output

The output has the same axes and size as the input and the same representation: a numeric array for an array input, or the GSR.dat file (saved in the save folder) for a .dat input.

Note
For event-split data, every E slice is regressed as an independent Y-X-T recording, with its own mean, global signal and invalid pixel traces; the mask is shared by all E slices. Ignored event instances are processed like the others, so the E axis of the output still matches events.mat. Invalid pixel traces are identified from the first frame only: a NaN in the first frame marks the whole pixel trace as invalid.

Parameters

The parameters of this function are the following:

If set to true, the function will use the logical mask stored in the DataParams.mat file of the save folder (DataParams.mask.logical) to calculate the global signal based on the pixels inside the mask. If set to false, all pixels from the image will be used to calculate the global signal.

Normally, if the image contains areas that are not a region of interest (e.g. the brain surface), it is advisable to create and use a logical mask to exclude these areas. A logical mask is created using the ROImanager app. Read the app's documentation to learn how to create a logical mask.

Note
If DataParams.mat is missing, or if the stored mask is empty or all true, a warning is raised and the function falls back to using the full frame.
