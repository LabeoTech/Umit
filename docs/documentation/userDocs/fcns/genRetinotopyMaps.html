genRetinotopyMaps

Creates azimuth and elevation maps from retinotopic mapping recordings.

Description

This function generates the amplitude and phase components of the azimuth and elevation retinotopic maps. The maps are created from the cortical responses to a periodic stimulus [1-4].

Input

This function accepts only continuous image time series with dimensions Y, X and T, stored in a .dat file. UMT structs and .umt files are not supported. When called directly from MATLAB, a numeric Y x X x T array is also accepted; in that case the frame rate must be given explicitly with the FrameRateHz parameter.

The input data must contain the cortical responses to at least two opposite directions in order to calculate either the azimuth or elevation maps. The directions of the visual stimuli are encoded in degrees where the cardinal directions left-right, bottom-up, right-left and top-down correspond to 0°, 90°, 180° and 270°, respectively. This information should be stored in an events.mat file located in the Save Folder (it must contain eventID, timestamps, state and eventNameList). If the events use generic names instead of the standard direction labels, the function standardizes them according to the Direction parameter in memory (without modifying the file on disk) and issues a warning.

For .dat input, the Fourier transform is computed in blocks of image columns, so the recording is never loaded whole into memory. Only the final Y x X amplitude and phase maps are kept in memory.

The algorithm

For each direction, the fourier transform is performed in the time domain and the first harmonic (i.e. at the stimulation frequency) is selected to calculate the amplitude and phase maps. The directions 0° and 180° are combined to create the azimuth map while the directions 90° and 270° are combined to create the elevation map. The amplitude of opposign directions are averaged while the phases are subtracted in order to remove the response phase delay as proposed by Kalatsky and Stryker [1].

Output

The genRetinotopyMaps function creates a single .umt file (default name retinotopyMaps.umt) containing the following entries:

  • AzimuthMap
  • ElevationMap

Each entry has dimensions {'Y','X','F'}, where F has two slices: amplitude (first) and phase (second). Only the entries of the selected Direction are created. See Organization of .umt files for the file format. The output can be used directly by genVSM. If the phase map is not rescaled to visual angle, the phase values will range between 0 and 2π. If the screen sizes and visual distance are provided, the ouput will be rescaled to match the visual angle in degrees (see below for the necessary criteria). In this case, the visual angle origin (0,0) will be placed at the center of the screen.

In order to rescale the phase map values to location units in the visual space (i.e. visual angle), the following criteria should be met (see [5] for more details):

  • The optic axis of the eye should be perpendicular to the screen surface.
  • The optic axis of the eye should point to the center of the screen.
  • The full extent of the screen must be visible to the animal point of view.

Parameters

The parameters of this function are the following:

Selects which maps are created. All creates both the azimuth and elevation maps, while Azimuth_only and Elevation_only create only the corresponding map. The number of stimulus sweeps, which is used to select the first harmonic, is derived automatically from the events in events.mat; it is not a parameter.

This is used in [4] to calculate the azimuth and elevation maps. Set this parameter to true to preprocess each direction movie as the average of each trial normalized by the median of an inter-trial period. To make this work, the trigger timestamps of each trial must be stored in the events.mat file and an inter-trial time period between trial must exist.

If the average movie is used, a single sweep is analyzed, given that each trial represents a single sweep of the visual stimulus.

Note
When this parameter is false, only the stimulus-on to stimulus-off epochs are concatenated before the Fourier transform; the inter-stimulus gaps are excluded. This introduces discontinuities between epochs, and the maps are not numerically comparable with those of previous releases, which transformed one contiguous span from the first onset to the last offset.

This corresponds to the distance in centimeters between the animal's eye and the screen. This measure is used to rescale the phase maps to visual angle in degrees. If set to zero, no rescaling is applied.

This corresponds to the horizontal length of the screen in centimeters. This measure is used to rescale the phase maps to visual angle in degrees. If set to zero, no rescaling is applied.

This corresponds to the vertical length of the screen in centimeters. This measure is used to rescale the phase maps to visual angle in degrees. If set to zero, no rescaling is applied.

Frame rate of the input data in Hz. When the function runs in a pipeline, the value is taken from the data automatically, and a .dat file otherwise provides it in its header. An explicit value overrides the header (a warning is issued if they differ). It is required for numeric array input.
