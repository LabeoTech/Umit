run_HemoCompute

Calculates HbO and HbR from reflectance signals.

Description

This wrapper uses reflectance (intrinsic) signals to estimate changes in oxygenated (HbO) and deoxygenated (HbR) hemoglobin. It resolves illumination spectra, camera responses, and filter transmission from the Rig associated with the acquisition. If the acquisition does not identify a Rig, the active default Rig is used with a warning and the acquisition metadata is not modified.

Input

Call the wrapper as run_HemoCompute(SaveFolder, data, ...).

  • SaveFolder contains AcqInfos.mat and the imported reflectance channels.
  • data selects the execution mode; its pixel values are not processed directly. A numeric Y-X-T array selects standard mode, while a .dat filename selects RAM-safe mode.

HemoCompute reads the two or three channels selected by Illuminations from the SaveFolder. Supported canonical names are red, green, and yellow; the historical name amber is normalized to yellow. Imported channel filenames and timebases are resolved from AcqInfos.mat. Four-dimensional event-split input is not supported.

Output

Every execution mode writes HbO.dat and HbR.dat in the SaveFolder. With one requested output, the wrapper returns the manifest {'HbO.dat','HbR.dat'}. With two requested outputs, it returns those two filenames individually; it does not return numeric arrays. 

files = run_HemoCompute(saveFolder, data);
[hbOFile, hbRFile] = run_HemoCompute(saveFolder, data);
hbO = loadData(fullfile(saveFolder, hbOFile));

Call the lower-level HemoCompute function directly when its numeric standard-mode arrays are required instead of file-backed wrapper outputs.

Parameters

Set of excitation and emission filters used in recordings:

  • GCaMP: Filter set from recordings using GCaMP as a fluorophore
  • jRGECO: Filter set from recordings using jRGECO as a fluorophore
  • none: No filter set

Set this parameter to true to apply a band-pass temporal filter and normalize the data prior to the calculation of the HbR and HbO. The band-pass cut-off values are 1 and 1/120 Hz. Set to false to skip the normalization if the input data is already normalized.

If the data from the input files are already normalized (i.e. with an average around 0 or 1) and this parameter is set to true, the normalization will be skipped. However, if it is set to false and the input data is not normalized, the computation will be aborted. The normalized data is necessary for the execution of this algorithm.

Select two or three different channels from red, green, and yellow. The selected channels must exist in the SaveFolder and be represented by the acquisition and Rig optical configuration.

Sets the assumed total hemoglobin concentration in micromolar.

Sets the assumed tissue oxygen saturation as a percentage.
