createRegistrationTform

Estimate and store a 2-D transform that aligns one Save Folder image to its reference image.

Description

The required fixed image must already be stored in DataParams.registration.referenceImage. The function selects a moving .dat, reduces Y-X-T data to one image, estimates a similarity transform, calculates advisory quality-control metrics, and updates DataParams.mat.

No .dat samples are changed.
This function estimates and stores a candidate only. Use applyRegistrationTformOnFolder separately after visual review.

Input

SaveFolder must contain valid DataParams.mat, AcqInfos.mat, and one or more eligible .dat files.

Output

outFile is a file manifest containing the updated DataParams.mat and timestamped QC .fig and .png files.

Parameters

auto selects the first eligible .dat in the folder. Supply a filename to control which channel or processing stage is registered.

When false, the same QC figure and PNG are generated invisibly for non-interactive processing.

Chooses the statistic used to collapse Y-X-T into the 2-D moving image. If needed, that image is resized to the reference size before registration.

QC metrics are advisory.
Inspect anatomical alignment and borders visually. A higher numerical metric does not guarantee a scientifically acceptable transform.
