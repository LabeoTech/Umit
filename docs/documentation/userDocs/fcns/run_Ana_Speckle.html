run_Ana_Speckle

Calculates the blood flow from the Laser Contrast Speckle Imaging (LSCI) data.

Description

This function uses the raw LSCI data stored in a speckle .dat file (typically speckle.dat) and calculates flow of imaged blood vessels (in arbitrary units). The algorithm used in this function is described in [1]. The function always works file-to-file: the file is read, processed and written in chunks, so the whole recording is never loaded into memory.

Input

The name of a .dat file in the save folder containing the raw LSCI image time series, with dimensions Y,X,T. Numeric arrays, other file types and other dimension layouts are not supported. The layout is checked before processing, so a rejected file produces no output.

Output

The file Flow.dat, written in the save folder: a single-precision image time series with dimensions Y,X,T containing blood-flow values in arbitrary units. It has the same axes, sampling rate and exposure as the input file.

Parameters

If true, the function normalizes the blood flow values of each pixel by its temporal average.

References

  1. Boas, David A., and Andrew K. Dunn. ‘Laser Speckle Contrast Imaging in Biomedical Optics’. Journal of Biomedical Optics 15, no. 1 (February 2010): 011109. https://doi.org/10.1117/1.3285504.
