genImageTimeSeriesUMT

Package an in-memory image time series as a validated UMT structure.

Description

The function replaces older ad hoc packaging with genUMTStruct. It declares image kind and Y-X-T dimensions, optionally adds top-level labels, and validates the result before returning it.

Input

A numeric or logical Y-X-T array held in RAM. Filename input is not supported.

Output

A UMT structure with kind='image' and one named entry with dimNames={'Y','X','T'}. PipelineManager passes the structure downstream and manages the default imageTimeSeries.umt file when persistence is required.

Parameters

Names the entry under outData.data. Choose a short scientific name such as correctedFluorescence.

Use labels only when they describe declared axes or observations. Do not place project identity or folder-wide metadata here.

Validation includes event rules.
The returned structure is checked with event information required when the schema and dimensions call for it. Keep labels and any later event metadata aligned with the entry value.
