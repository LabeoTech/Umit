applyRegistrationTformOnFolder

Apply the registration transform stored in a Save Folder to every .dat file in that folder.

Destructive and effectively irreversible
This function rewrites every .dat file in place. Interpolation and pixels moved outside the frame cannot be recovered reliably. Back up the folder and inspect the quality-control image before continuing.

Description

The function loads DataParams.registration.tform, streams each frame through the transform, writes a temporary file, and then replaces the original .dat. It updates registration status in DataParams.mat. Reapplication is blocked by default when the folder is already marked registered.

Input

SaveFolder must contain a valid DataParams file, a stored transform, authoritative acquisition metadata, and at least one .dat file.

Output

There is no normal data output. The modified filenames and updated DataParams path are printed to the MATLAB command window.

Parameters

Selects the MAT-file containing the scalar DataParams structure.

When true, the function asks the user to continue. Disabling it records a forced-no-confirmation mode and should be reserved for controlled, backed-up automation.

If a QC figure path is stored and the file exists, the figure opens before the confirmation dialog.

The default prevents accidental interpolation of already registered data. Set true only when the repeated operation is intentional and reviewed.
