genAmplitudeMaps

Calculate one response-minus-baseline image for each event condition.

Description

For every condition, the function aggregates baseline samples and response samples, subtracts the baseline map from the response map, and aggregates repetitions. Continuous data uses Save Folder events.mat. Event-split UMT data uses its top-level eventInfo.

Input

InputRequirements
Numeric Y-X-TContinuous data; valid events.mat in SaveFolder.
.dat filenameContinuous data; uses low-RAM spatial slabs and events.mat.
UMT structure or .umt fileExactly one compatible image entry with Y-X-T or Y-X-T-E dimensions. Continuous Y-X-T also requires events.mat; Y-X-T-E requires valid eventInfo and FrameRateHz.

Output

A validated image UMT with entry AmplitudeMap, dimensions Y-X-E, aggregated event information, and the selected measures/time window in entry metadata. PipelineManager manages the default amplitudeMap.umt persistence.

Parameters

The result becomes the baseline map for each event condition.

The response map is calculated across the selected response frames and repetitions before baseline subtraction.

all uses every frame after the baseline. A numeric non-negative interval is measured in seconds after the baseline and must fit inside each trial.

Low-RAM .dat behavior
The file branch reads event frame slabs in X chunks instead of loading the full recording. The scientific calculation and output schema match the in-memory branch.
