Organization of .umt files

UMT is umIT's schema-validated MATLAB container for processed and derived data. It carries enough dimension and event meaning to remain interpretable after being copied out of its original Save Folder.

Top-level schema (version 1)

FieldRequired?Meaning
versionYesUMT schema version used for validation and compatibility.
kindYesimage or roi; selects allowed dimension patterns.
dataYesStructure of named entries.
labelsNoTop-level labels that describe declared axes or observations.
eventInfoWhen the event axis requires itShared event identifiers, names, repetition representation, and optional baseline.

Entries

Every data.<entryName> has a numeric/logical value and ordered dimNames. Optional entry meta contains processing facts such as FrameRateHz. The number and order of dimension names must match the value and an allowed pattern for the UMT kind.

Event information

FieldMeaning
eventIDCondition ID for each event-axis element.
repetitionIndexRepetition number, or zero for an aggregated representation.
eventNameHuman-readable condition name aligned with IDs.
eventAxisModeinstances or aggregated_repetitions.
baselinePeriodOptional baseline duration in seconds.

Create, append, and validate

umt = genUMTStruct(value, ...
    'kind','image', ...
    'entryName','main', ...
    'dimNames',{'Y','X','T'}, ...
    'SaveFolder',saveFolder);
validateUMTStruct(umt,'requireEventInfo',false);

Use genUMTStruct for creation/appending and appendUMTEventInfo for event metadata. PipelineManager persists returned UMT structures when the output plan requires a file.

Identity boundaries

UMT does not embed project, subject, or session identity. Those facts belong to the centralized project store and Save Folder binding. UMT can carry scientific labels and processing metadata, but it must not become a portable copy of the project database or folder-wide mask/Raw Folder state.

Backward compatibility and editing

The version field allows validators and controlled migrations to distinguish schema revisions. Validate every loaded or programmatically changed UMT. Direct manual field editing is unsupported because apparently small changes can invalidate dimensions, labels, or event alignment.
